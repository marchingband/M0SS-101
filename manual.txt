M0SS-101 MANUAL

M0SS-101 is a monophonic virtual analog synth, programmed in the Faust DSP language, on the BL616 microcontroller, which includes:

2 oscilators (OSC), with stackable square and sawtooth waveforms, each with octave and pulse width (PW) control. Oscilator 2 can be detune.
1 filter (VCF), with high-pass, low-pass or bandpass response, resonance control, and optional key-tracking.
1 low frequency oscilator (LFO), with square, triangle, or random (sample and hold) wavforms, and a frequency range of 0.01hz to 10khz.
1 amplifier (VCA)
1 envelope generator (ENV), with attack, decay, sustain and release controls, with timings from 0.1ms to 20s, adjustable curves, and a special inversion mode.
1 noise generator (NSE) with pink or white noise algorithms.
1 XOR module applied to the 2 oscilators.
1 mixer (MXR) with inputs from each oscillator, the noise generator, and the XOR module.
1 delay module, with time, feedback, and mix controls.
1 glide module with adjustable speed.
1 pichbend module with adjustable upward and downward range.
9 patch-points with gain, connecting the LFO and ENV to the VCF cutoff, PW, OSC pitch, and VCA, or to trigger the ENV from the LFO square wave.
1 flash memory unit to store up to 17 presets, and to remap MIDI channels per preset.
2 MIDI inputs (USB Host and 1/8" Type-A input), with OMNI / assignable channel.
1 MIDI thru 1/8" Type-A output.
1 1/4" mono audio output, line level, 100kohm impedance.
1 9V dc power input, center negative.
1 knob to adjust parameters, which can be depressed (click) to trigger the ENV.

The primary function of each control is stamped above the control.
The seconary function is stamped to the right, or beneath the control, hold ATL to access the secondary function.

If you activate a control, the row of bulbs near the bottom will often display its value in one of two ways:
FADER: this shows a value from 0 to 100, each bulb represents 10, and its faded value represents the 1's.
SWITCH: the left 5 bulbs glow for on, the right 5 for off.

Sometimes a control will have a specific number to indicate, for example MIDI channel.
In this case a bulb will light near a control which has a small number stamped to its left. There are bulbs and controls for numbers 1 ~ 17.

SAVE
1) Activate save mode (ALT + CTF) - free slots glow green, occupied slots glow pink.
2) Press any slot to save (this can overwrite a slot).

LOAD
1) Activate load mode (ALT + RES) - current slot glows blue, loadable slots glow green.
2) Press any loadable slot to load it (you will lose your current settings, if not saved).

MIDI LEARN
1) Activate MIDI learn mode (ALT + ENV.PWM) - bulbs all glow pink
2) Select any control parameter             - bulbs all glow green
3) Send any MIDI CC                         - bulbs all glow blue
(optionally repeat steps 2 and 3)
4) Press ALT to exit
This CC is now mapped to that contol parameter. Save the preset to conserve this map.

ENV INVERSION
When this control is active (it is active by default) attenuating the ENV.VCA signal will result in a higher minimum gain for this signal.
When this control is deactivated, the ENV.VCA signal operates more intuitively, where attenuating the signal results in a lower maximum gain.
Activating ENV inversion allows the composer to give the VCF, or the LFO, more control over the output signal.
For example, with ENV inversion active, when ENV.VCA is set to 0, the VCA is always open. Now using the LP filter, with CTF set to 0, there is no sound.
Now setting ENV.VCF to 10, the ENV will use the VFC to open and close the sound according to its envelope, with a rich and filtered timbre.

There are some unmarked controls:
hold (ALT + LFO.VCF)                = pichbend down semitones (1 ~ 12)
hold (ALT + LFO.OSC)                = pichbend up semitones (1 ~ 12)
hold (ALT + LFO.PWM)                = MIDI channel (1 ~ 17, 17 = OMNI)
hold (ALT + A)                      = ENV curves (1 ~ 9) (1 = very logarithmic, 5 = linear, 9 = very exponential)
hold ALT + click knob + turn knob   = transpose pitch (semitones)
hold ALT + turn knob                = fine-tune pitch (cents)
Alt + ENV.VCA                       = ENV inversion mode (de)ativate

OSC-2 or OS2 = oscilator two
WAV          = waveform

PW           = pulse width

MXR          = mixer
NSE          = noise generator

WN.PN        = white noise or pink noise
TRI          = triangle waveform

FRQ          = frequency
LO-HI        = low or high range
CTF          = cutoff
RES          = resonance
HP           = high pass
LP           = low pass
BP           = band pass
K-T          = key tracking
A            = attack

R            = release
D-TM         = delay time
D-FB         = delay feedback
D-MX         = delay mix with master
